# Junsuk Choe Homepage

Static personal academic homepage for GitHub Pages.

## Preview locally

Open `index.html` in a browser.

## Publish with GitHub Pages

1. Create a GitHub repository named `junsukchoe.github.io`.
2. Upload the files in this folder to the repository.
3. In the repository settings, enable GitHub Pages from the `main` branch and the root folder.
4. Visit `https://junsukchoe.github.io` after GitHub finishes publishing.

## Update notes

- Edit `index.html` for content changes.
- Edit `styles.css` for visual changes.
- Replace `assets/profile.jpg` to change the profile photo.
